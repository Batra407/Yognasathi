# Raw Official Scheme Information Directory

This directory (`data/raw/official_scheme_information/`) is reserved for storing untouched original data files (JSON/CSV/XML) fetched from official government APIs or open-data resources (such as myScheme API via API Setu or data.gov.in).

- **Dataset A (Budget Outlays)**: `data/raw/government_schemes_original.csv`
- **Dataset B (Scheme Metadata & Eligibility)**: `data/raw/official_scheme_information/`

Do not modify or overwrite untouched files stored in this directory.
